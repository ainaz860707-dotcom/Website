Речь о **золоте по чёрному** — токены проверены в браузере на `artifacts/jewel-shop/index.html`:

```

--panel: #141216  карточка
--raise: #1B181D  поднятая поверхность
--paper: #F2EDE4  текст
--dim: #9B948A    второстепенный текст
--gold: #C9A227   акцент, кнопка, цена
--gold-soft: #E7D08A  подсветка, бренд, крупные числа
--line: rgba(201,162,39,.26)     золотая линейка
--line-soft: rgba(242,237,228,.12) обычная линейка
градиент золота: #A9821B → #C9A227 → #E7D08A → #F6E7B8
```

Сопутствующее из того же захода: заголовки Literata, текст Jost, радиус 4px, зерно поверх листа,
градиент на акцентном слове заголовка через `background-clip: text`.

**Why:** это первая палитра, которую владелец назвал понравившейся сам, без выбора из вариантов;
до этого он трижды правил направление («слишком темно», «в золоте и в чёрном»). Значит по
умолчанию для его проектов берётся она, а не тёплая бумага из каталога направлений.

**How to apply:** предлагая направление под его задачу, ставить эту гамму первой и говорить, что
она уже принята; отступать — только если ниша ей прямо противоречит, и сказать чем. Не путать с
выбором направления по [[feedback_design-board-refs]]: доска остаётся, но фаворит известен.
Живой образец — `artifacts/jewel-shop/index.html`, разбор в `plans/jewel-shop.md`.
