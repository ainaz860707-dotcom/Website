# Memory index

- [Спрашивать «записать?»](feedback_ask-to-record.md) — важный вывод фиксируется одним коротким вопросом, а не меню вариантов; «да» = запись в правила, second-brain и скилл сразу.
- [Скиллы зовёт агент, а не владелец](feedback_agent-invokes-skills.md) — подходящий скилл вызывается сам, без команды и напоминания; «скажете — вызову» вместо вызова — нарушение.
- [Не сочинять факты о бизнесе клиента](project_no-invented-facts.md) — на странице только то, что клиент сказал во входе; остальное плейсхолдер, наследуется каждым режимом продукта.
- [Чужому скиллу — русские триггеры](feedback_external-skill-russian-triggers.md) — без русских фраз в `description` внешний скилл молча никогда не вызовется; тело `SKILL.md` не переводить.
- [CSS-рецепт в правиле — замерять браузером](feedback_css-recipe-must-be-measured.md) — сборка и дифф таких дефектов не видят; `paused` + `opacity:1` не показывает кадр, hover без `@media (hover: hover)` мёртв на телефоне.
- [Когда прогон генератора не нужен](feedback_prompt-example-vs-prose-rule.md) — пример кода в промпте модель копирует дословно, прогон нужен только под правило прозой или непроверенный пресет; страница стоит 0.67 USD.
- [Доска дизайна всегда с референсами](feedback_design-board-refs.md) — `--refs` обязателен: Awwwards даёт живые сайты и токены, Dribbble только картинки; запрос к Dribbble английский.
- [Ключ в `.env` вписывает владелец](feedback_owner-writes-secrets.md) — агенту доступно только `echo 'ИМЯ=' >> .env`; перенос значения и откат шаблона — команды владельцу, проверка ключа делом, а не grep'ом.
- [Адрес remote-MCP проверять curl](feedback_remote-mcp-probe.md) — README пакета опережает деплой сервиса; `404` — эндпоинта нет, `401` с `www-authenticate` — живой адрес, ждёт входа.
- [Скрипт страницы обязан выполниться](feedback_page-script-must-run.md) — чекер зелёный при упавшем скрипте; `const top` роняет весь блок, ловится только pageerror в браузере.
