Владелец показывает референсы движения ссылками на Instagram Reels («могу только ссылки в инстаграм»).
Рабочий путь: `yt-dlp` качает публичный reel по ссылке, `ffmpeg -vf "fps=2,scale=-1:420,tile=6x5"`
собирает контактный лист — один лист читается вместо тридцати кадров. Крупные детали (адресная
строка, мелкий текст) — отдельными кадрами `-ss <секунда> -frames:v 1` в полном разрешении.

**Почему:** «видео смотреть не умею» — ложный отказ; ролик разбирается по кадрам, и адресная строка
в кадре часто выдаёт живой сайт, у которого стек снимается `curl` + grep по бандлу вместо догадок.
В ffmpeg 9 нет `-vsync` (только `-fps_mode`) и нет фильтра `drawtext` в бутылке homebrew.

**Как применять:** сразу после ссылки ставить `brew install yt-dlp ffmpeg`, качать в скратчпад,
резать листы, и только потом говорить о приёмах. Если в кадре виден домен — проверить стек по
живому сайту и мерить текст в HTML, как в [[project_no-invented-facts]] мерится честность фактов.
Приёмы движения называть ключами каталога `tools/motion-directions.mjs`.
