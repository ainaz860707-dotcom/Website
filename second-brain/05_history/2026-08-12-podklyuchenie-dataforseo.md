# Подключение DataForSEO MCP

## Что поставлено

«Добавь DataForSEO MCP» — одна строка от владельца, без уточнений про транспорт и авторизацию.

## Как решал

Пакетов с именем DataForSEO в npm полтора десятка; официальный — `dataforseo-mcp-server`
издателя `dataforseo`, версия 3.0.0 от 2026-08-11. Распаковал `npm pack` и прочитал README
вместо того, чтобы конфигурировать по памяти.

README даёт два транспорта. Выбрал remote HTTP с OAuth, а не stdio с логином и паролем
в `env`-блоке: §4 держит секреты в ENV, а OAuth не кладёт их вообще никуда.

Адрес из README — `https://data.dataforseo.com/v3/mcp` — записал в конфиг и проверил `curl`.
Получил `404 {"message":"The route v3/mcp could not be found."}`. Перебрал соседние адреса:
живым оказался `https://mcp.dataforseo.com/mcp` — `401` с заголовком
`www-authenticate: Bearer … resource_metadata=…` и работающим OAuth-дискавери. То есть v3-хостинг
ещё не выкачен, README опережает деплой на день.

Разница между «сервера нет» и «сервер требует входа» читается ровно по этим двум ответам:
`404` с телом про маршрут против `401` с `www-authenticate`. Без этой проверки в конфиге лежал бы
мёртвый адрес, а симптом выглядел бы как поломка клиента — сервер просто не поднимается.

## Что вышло

- `.mcp.json` — сервер `dataforseo`, remote HTTP. Файл в `.gitignore`, под git не идёт.
- `.claude/CLAUDE.md` — раздел политики: порядок `docs_*` → `api_request` и граница с §12.
- Коммит `0896e72`. В него же уехали лежавшие незакоммиченными разделы `gsap`, `magicui`
  и добавленный владельцем `snyk` — разделить нельзя, `git add -i` в этой среде недоступен.
- Знание — [[../02_architecture/search-data-source]], блокер — строка в `04_not-done`.

Проверить работу инструментов не мог: до авторизации владельца MCP не отдаёт ни одного вызова.
Так и доложено — «подключено», а не «работает».

## Чему научился

Адрес remote-MCP из README проверяется `curl` до записи в конфиг. Пакет и хостинг у таких
сервисов выкатываются раздельно, и документация регулярно описывает эндпоинт, которого ещё нет.
Правило вынесено в `memory/feedback_remote-mcp-probe.md`.

Второе, помельче: `.mcp.json` в этом репозитории игнорируется. «Добавил MCP» здесь значит
«добавил на этой машине» — переносимой остаётся только заметка и раздел в правилах тулинга.
