# Установка скилла security-review от Sentry

## Что поставлено

Владелец попросил поставить скилл `security-review` из `github.com/getsentry/skills`.
Скопирована одна папка из 28 в `.claude/skills/security-review/` — 21 markdown и файл
атрибуции OWASP. Коммит `670ce0a`.

## Как решал

Клонировал репозиторий в scratchpad и проверил три вещи до копирования: нет
исполняемых файлов (`find ... ! -name '*.md'` дал только `LICENSE` — вслепую ничего не
запустится), нет Sentry-специфичного содержимого (`grep -riE 'sentry|getsentry'` по
скиллу пуст), лицензии совместимы (репозиторий Apache-2.0, справочники — OWASP
CC BY-SA 4.0, атрибуция внутри скилла сохранена).

Два решения принял сам по §1 «техвопросы владельцу не задаются»:

1. **Имя оставил конфликтным.** У Claude Code есть встроенный `security-review`;
   проектный скилл его перекрывает. Основание — у Sentry 18 справочников против
   одностраничного встроенного. Разбор — [[../02_architecture/security-review-skill]].
2. **Дописал русские триггеры в `description`.** Автозагрузка идёт матчингом по тексту
   `description`, владелец пишет по-русски. Ровно та же правка делалась при установке
   пака `taste-skill` и пака SEO/GEO — практика третий раз подряд.

## Что вышло

Коммит `670ce0a`, 23 файла, +8378 строк. Кода проекта правка не касается — сборку и
тесты не гоняла, гонять нечего: изменены только markdown в `.claude/skills/` и одна
секция ростера.

README ростера содержал несохранённые правки другой сессии (пак `taste-skill`), поэтому
стейджил свои 11 строк частичным патчем через `git apply --cached`, а не `git add`
целиком. Чужие строки остались в рабочем дереве нетронутыми.

## Чему научился

Установка чужого скилла — это не только копирование. Три проверки до `cp` (исполняемые
файлы, чужая специфика внутри, лицензия) и одна правка после (русские триггеры в
`description`) повторились уже трижды: `taste-skill`, SEO/GEO, теперь Sentry.
Повторяющаяся процедура на несколько шагов по развилке `UPDATE_AFTER_CODE_CHANGE`
просится в скилл, но третий повтор — это ещё не доказанный порог допуска: нет прибора,
который показал бы цену пропуска шага. Строка о находке ушла в `04_not-done`.

## Что осталось нерешённым

Проверка «скилл действительно вызывается на русскую фразу» глазами не сделана: реестр
скиллов читается на старте сессии, в текущей сессии новый скилл не виден. Проверяется
первой же фразой «проверь безопасность» в следующей сессии.
