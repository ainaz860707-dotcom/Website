# Референсы при генерации

## Решение владельца

Генератор берёт дизайн не из зашитого списка направлений, а из живых сайтов, которые
курирует Mobbin под нишу клиента. Решение владельца от 2026-08-10; возражение о цене
живого прохода на каждого клиента снято кэшем по нише.

## Как устроено

```
описание бизнеса
  → nicheProfile(): признаки текста, а не список ниш → профиль + стили Mobbin
  → кэш references/niches/<key>.json свежее 30 дней? отдаём его, сети нет
  → иначе Chrome с сессией владельца → POST /api/search/fetch-search-page-sites
  → отсев технологических taglines → первые 4 сайта, с которых снялись стили
  → extractTokens() по живому сайту: шрифты, цвета, шкала кеглей, радиусы, кривые
  → synthesizeDirection(): палитра, пара шрифтов, ритм → JSON в кэш
  → probe-site-gen подставляет в промпт вместо встроенного направления
```

## Почему нужен именно браузер

`POST` к API Mobbin без куки отвечает `{"error":{"message":"unauthenticated"}}`. Сессия
живёт в профиле `ms-playwright-mcp/mcp-chrome-2d32ba4`, детали — [[reference-sources-access]].
Playwright поднимает этот профиль в headless поверх установленного Chrome
(`channel: 'chrome'`), поэтому движок браузера не скачивается.

## Что решает признаковый разбор ниши

Раньше `pickDirection` искал слово ниши в списке; не нашлось — дизайн выдавался по остатку
от деления. Профили опираются на признаки: продаёт картинку · еда и ремесло · здоровье ·
документы и деньги · работа руками · обучение. Тату-мастер и флорист попадают в тот же
профиль, что фотограф, не будучи перечисленными.

## Отказы устроены громко

Сессия потеряна, профиль занят окном, Mobbin вернул пусто — генератор пишет причину в
stderr и берёт встроенное направление. Молчаливой подмены нет: строка `[референсы]`
в логе прогона говорит, откуда взялся дизайн.

## Границы

- Точность акцентного цвета — самое слабое место: дефолты фреймворков отсеиваются списком,
  остальное берётся по частоте. Проверять глазами.
- Коммерческие шрифты референсов (Caslon Ionic, GillSansNova) на Google Fonts отсутствуют —
  в дирекшене прямо сказано брать ближайшую пару, подстановку делает модель.
- Работает на машине владельца; на сервере сессии нет — строка в `04_not-done`.
