# Грабли в коде: симптом → корневая причина → чем защищено

Заводится скиллом `debug-recovery` после каждой пойманной поломки: симптом словами владельца,
причина уровня механизма, чистый фикс и тест, который не даст ей вернуться.

## Гравюра Милле на первом экране химчистки (2026-08-17)

**Симптом.** На первом экране страницы химчистки вместо фотографии стояла сепийная гравюра XIX века:
крестьянка в поле. Автоматические проверки молчали — `check-page.mjs` видит `<img>` с `alt`, `width`
и `loading`, а что на кадре, он не смотрит; визуальный критик поставил 4.4 из 5 и кадр не заметил.

**Корневая причина.** `search()` в `tools/stock-photos.mjs` собирал запрос к Openverse без параметра
`category`, поэтому наравне с фотографиями приходила оцифрованная живопись из rawpixel
(`category: null`), и по релевантности гравюра Милле «Woman Hanging Clothes» встала первой в выдаче
по запросу `hanging clothes` — первый кадр из набора уходит на первый экран.

**Подтверждение до фикса.** Один и тот же запрос с `&category=photograph` и без него: без фильтра
в восьмёрке три позиции с `category: null`, включая ту самую гравюру; с фильтром — ноль.

**Чистый фикс.** `category=photograph` в строке запроса плюс отсев по полю ответа
(`photographsOnly`): параметр может быть проигнорирован сервером, поле в ответе — факт.

**Защищено.** `tests/stock-photos.test.mjs`, три теста: фильтр в URL, отсев живописи по ответу,
и что уход за одеждой не уезжает в свадебную фотографию (та же поломка на слое ниши).

**Остаточный дефект, фиксом не закрытый.** Даже с фильтром бесплатный банк (stocksnap + rawpixel,
только CC0) для этой ниши пуст: `ironing` отдаёт ржавое железо и чугунную решётку, `silk fabric` —
яркие сари, а часть сканов гравюр помечена `photograph` самим rawpixel. Значит для премиальной
нейтральной съёмки одежды бесплатный банк не годится — кадры генерируются (`tools/bfl-image.mjs`),
и это деньги, решение владельца. Строка в [[../04_not-done/README|реестре не-сделанного]].

**Урок шире одного бага.** Проверка «картинка есть и подписана» не проверяет, что на картинке.
Между `collectPhotos` и страницей нужен глаз: контактный лист из скачанных кадров одним снимком —
15 кадров видно сразу, брак ловится до вёрстки, а не после.
