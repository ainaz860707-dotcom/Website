# Источник данных поиска

## Зачем понадобился

[[seo-geo-skills]] дают метод, но не дают цифр: ни один из 16 скиллов не ходит в платные API,
частотность и позиции ждут выгрузки от владельца. DataForSEO закрывает эту дыру — частотность,
выдача, конкуренты, бэклинки, аудит страницы приходят из API.

## Транспорт: remote HTTP с OAuth

```json
"dataforseo": { "type": "http", "url": "https://mcp.dataforseo.com/mcp" }
```

Логин и пароль на диске не лежат: сервер отдаёт OAuth-дискавери, авторизация — команда `/mcp`.
Альтернатива из README — stdio `npx dataforseo-mcp-server --mode stdio` с `DATAFORSEO_LOGIN` и
`DATAFORSEO_PASSWORD` в `env`-блоке конфига; отвергнута, потому что кладёт пару логин-пароль
в файл.

## Ловушка: адрес из README не работает

README пакета `dataforseo-mcp-server@3.0.0` (опубликован 2026-08-11) называет remote-адресом
`https://data.dataforseo.com/v3/mcp`. Хостинг под него не выкачен:

| Адрес | Ответ на `POST initialize` |
|---|---|
| `https://data.dataforseo.com/v3/mcp` | `404 {"message":"The route v3/mcp could not be found."}` |
| `https://data.dataforseo.com/mcp` | `404` |
| `https://mcp.dataforseo.com/mcp` | `401` + `www-authenticate: Bearer … resource_metadata=…` |

`401` с заголовком `www-authenticate` — это признак живого сервера, а не поломки: он говорит
«авторизуйся», а не «такого маршрута нет». Метаданные подтверждают:
`{"resource":"https://mcp.dataforseo.com/mcp","authorization_servers":["https://data.dataforseo.com"]}`.

Проверка адреса одним `curl` до записи в конфиг стоит минуту; без неё сервер молча не поднимается
и выглядит как поломка клиента.

## Порядок вызова инструментов

`docs_list_sections` / `docs_index` (какие эндпоинты есть) → `docs_search` (параметры конкретного
эндпоинта) → `api_request` (сам запрос). Порядок не декоративный: у DataForSEO сотни эндпоинтов
с разными полями, и `api_request` с сочинённым по памяти телом запроса — это тот же класс ошибки,
что §10а запрещает в коде.

## Граница с правилом §12

DataForSEO даёт факты о рынке и конкурентах, а не о бизнесе клиента. Цены, стаж, отзывы, адрес
и телефон, снятые с чужих страниц из выдачи, на страницу клиента не переносятся: во входе не
сказано — значит плейсхолдер. Основание — [[no-invented-facts]]. Риск здесь выше обычного, потому
что данные конкурента выглядят как настоящие и соблазн подставить их в разметку `LocalBusiness`
больше, чем соблазн выдумать с нуля.

## Состояние на 2026-08-12

Конфиг записан, авторизация не пройдена — аккаунт решение владельца (§1). Ни один запрос к API
не прогнан, поэтому лимиты, стоимость запроса и покрытие по русской выдаче неизвестны. Строка
в [[../04_not-done/README|реестре не-сделанного]].

`.mcp.json` лежит в `.gitignore` — конфиг серверов под git не идёт, на другой машине DataForSEO
прописывается заново. В репозитории остаётся только эта заметка и раздел в `.claude/CLAUDE.md`.
