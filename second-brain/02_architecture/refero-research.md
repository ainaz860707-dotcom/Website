# Refero — слой доказательств

## Что поставлено

`github.com/referodesign/refero_skill`, установка `npx skills add … --skill refero-design`
от 2026-08-19. Внутри — только markdown (`SKILL.md` + 10 справочников в `references/`)
и `agents/openai.yaml`; исполняемых файлов, хуков и команд нет, 156 КБ на диске.
Живёт в `.agents/skills/refero-design`, симлинк в `.claude/skills/` — как пак Remotion.

Скилл работает в двух режимах:

| Режим | Что даёт | Чего стоит |
|---|---|---|
| Встроенные справочники | типографика, цвет, ритм, движение, иконки, копирайт, anti-AI-slop, чек «reference lock» | бесплатно, аккаунт не нужен |
| Живой поиск через MCP | 150k+ экранов, стилей и флоу реальных продуктов, семантический запрос | подписка Refero Pro |

## MCP не подключён

Эндпоинт `https://api.refero.design/mcp` живой: `POST tools/list` без токена отвечает
`401` и `www-authenticate: Bearer resource_metadata=…` — адрес верный, ждёт входа.
Строка в `.mcp.json` не добавлена: без подписки сервер отдаёт `401` на каждый вызов,
а подписка — деньги, то есть решение владельца (§1). Подключение после оплаты — одна
команда:

```
claude mcp add --transport http refero https://api.refero.design/mcp
```

дальше `/mcp` в интерактивной сессии для OAuth-входа. Цена по открытым источникам —
12 USD в месяц или 120 USD в год, в Pro входит 8000 вызовов MCP в месяц; на сайте
цена не проверялась, страница отдаёт пустой SPA.

## Почему описание скилла переписано

В оригинале `description` объявлял себя «Primary/default skill for UI design» и требовал
предпочитать себя «frontend design, UI polish, landing page» скиллам. Это перебивало
обязательный маршрут проекта: разведка ниши, лестницы дизайн-системы, пресет движения,
вёрстка. Описание переписано так, чтобы скилл был источником доказательств внутри
`niche-benchmark` и перед `design-taste-frontend`, а не вместо них, и получил русские
триггеры — без них по русской фразе он не вызовется. Тело `SKILL.md` не тронуто.

## Граница с §12

Refero показывает чужие продукты. Текст, цена, отзыв, имя, цифра с найденного экрана
на страницу клиента не переносятся ни в каком виде — берётся визуальный язык и
структура, факты остаются из входа клиента. См. [[no-invented-facts]].
