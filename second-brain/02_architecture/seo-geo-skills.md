# Слой SEO/GEO-скиллов

## Откуда взято

Владелец назвал `github.com/aaron-he-zhu/seo-geo-claude-skills`. Этот репозиторий с
версии `v9.9.12` заморожен и превратился в указатель: живые скиллы переехали в
`github.com/aaron-he-zhu/aaron-marketing-skills` — бандл на 120 навыков семи дисциплин,
Apache-2.0, версия 19.2.0.

Поставлена **только дисциплина `seo-geo`** — 16 скиллов. Остальные 104 (соцсети, email,
платная реклама, инфлюенсеры, нарратив, запуск продукта) не поставлены сознательно:
каждый скилл висит в контекстном листинге каждой сессии, а к генератору сайтов эти
дисциплины отношения не имеют.

## Как разложено

Claude Code находит скилл только по пути `.claude/skills/<имя>/SKILL.md` — один уровень,
без вложенности. В бандле раскладка двухуровневая (`seo-geo/<фаза>/<скилл>/`), а сами
скиллы ссылаются на общие файлы бандла через `../../../references/…`.

```
.claude/skills/<скилл>/SKILL.md      16 директорий плоско
.claude/seo-geo-shared/              references · protocol · memory · scripts · CONNECTORS.md · SECURITY.md · LICENSE
```

Пути внутри скиллов переписаны машинно: `../../../X` → `../../seo-geo-shared/X`,
межскилловые `../../<фаза>/<скилл>/` → `../<скилл>/`. Все 100+ относительных ссылок
проверены на резолвинг — битых нет.

## Две локальные правки чужих скиллов

**Русские триггеры в `description`.** Исходные описания триггерятся на английский и
китайский. Владелец пишет по-русски — без этого скиллы просто не вызвались бы. В конец
каждого `description` дописана строка «Русские триггеры: …».

**Правило §12 в четырёх скиллах, порождающих текст** (`content-writer`,
`geo-content-optimizer`, `page-play-builder`, `serp-markup-builder`): блок-цитата сразу
после frontmatter — не сочинять цены, стаж, число клиентов, награды, имена, отзывы,
адрес, телефон, часы и гарантии, которых нет во входе; город не терять. Основание —
[[no-invented-facts]]. Разметка `LocalBusiness` и `Product` — прямая зона риска:
schema требует адрес, часы и цену, а модель охотно их придумывает.

Правки помечены здесь, потому что при обновлении бандла их придётся наложить заново.

## Что эти скиллы дают и чего не дают

Дают: разбор запросов и выдачи, разбор конкурентов, написание и обновление текста,
оптимизацию под цитирование нейросетями, мета-теги и JSON-LD, аудит страницы и техничку,
структуру и перелинковку, авторитет домена, позиции, отчёты и ссылочный профиль.

Не дают данных. Ни один скилл не ходит в платные API — объём запросов, KD, позиции и
бэклинки берутся из выгрузок, которые даёт владелец, либо из подключённых им коннекторов
(`.claude/seo-geo-shared/CONNECTORS.md`). Скилл без данных выдаёт метод и разметку
дефицита, а не цифры. Это ровно та же логика, что в [[citability]]: числа берутся с
замера, а не сочиняются.

## Пересечения с нашими скиллами

`niche-benchmark` разведывает нишу перед генерацией — `competitor-analysis` и
`serp-analysis` разбирают конкретную выдачу глубже и работают после. `citability`
описывает наш собственный замер цитируемости — `geo-content-optimizer` даёт чужую
методику под те же цели; сверять, а не заменять.
