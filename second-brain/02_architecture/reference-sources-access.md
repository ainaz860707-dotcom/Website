# Доступ к источникам референсов

## Решение

Источники за логином (Mobbin, Cosmos, Pinterest) открываются под сессией владельца
в **отдельном профиле Chrome**, которым управляет browser-MCP:

```
~/Library/Caches/ms-playwright-mcp/mcp-chrome-2d32ba4
```

Владелец входит руками один раз в окне этого профиля. Пароли агенту не передаются
и в репозиторий не попадают.

## Почему не личный Chrome владельца

Подключение MCP к личному профилю через `--remote-debugging-port` открывает автоматизации
весь профиль — почту, банки, все вкладки, — а не три сайта с референсами. Цена ошибки
несопоставима с экономией одного окна.

## Состояние на 2026-08-10

| Источник | Аккаунт | План | Проверено под сессией |
|---|---|---|---|
| Mobbin | `Айназ` | бесплатный, в шапке «Get Pro» | да, отдаёт каталог |
| Cosmos | `/ainaz77` | бесплатный | да, отдаёт категории и подборки |
| Pinterest | `/ainaz860707` | бесплатный | да, лента отдаётся; досок ноль |

Awwwards и NameThatUI читаются без входа.

## Профиль занят открытым окном

MCP не поднимет браузер, если окно этого профиля уже открыто: `Browser is already in use`.
Лечится закрытием окна — куки лежат на диске, вход не слетает. Не убивать процесс жёстко:
`kill -TERM` по главному pid, Chrome закрывается за 5–10 секунд.

## Как обходится пейволл Mobbin без оплаты

Бесплатный план режет **превью и разбор экранов**, но не режет **список**: в стиле
Photography отдались все 48 имён сайтов. Список виртуализирован — в DOM держится 6 карточек,
имена собираются накопительно по ходу прокрутки.

Отсюда рабочая схема: Mobbin даёт кураторский индекс «на что смотреть», а измеримые токены
(шрифты, палитра, шкала кеглей, радиусы) снимаются нашим `reference-tokens.mjs` с живого
сайта. Подписка для этой задачи не нужна.

## Как проверить, что сессия жива

Признаки гостя, по которым видно потерю сессии:

| Источник | Гость видит |
|---|---|
| Mobbin | редирект `/discover/...` → `/?redirect_to=...` |
| Cosmos | лендинг «Your space for inspiration» с кнопкой Sign up |
| Pinterest | форма логина вместо ленты |

Сессия потеряна — по правилу `niche-benchmark` это пишется строкой в отчёте по нише,
а не заменяется молча выдачей из поиска.

## Ограничение

Бесплатный Mobbin режет объём библиотеки. Упрёмся на реальной нише — вопрос денег,
решение владельца.
