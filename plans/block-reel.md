# Витрина блоков

**Задача (владелец, 2026-08-12):** не каталог стилей и не клиентский сайт, а одна длинная
страница, где блоки идут подряд и каждый устроен иначе — картинка, видео, карточки, сцена,
движение. Цель — разобраться, что вообще возможно. Текст в блоках значения не имеет.

- Файл: `artifacts/block-reel/index.html` · открыть: `open artifacts/block-reel/index.html`
- Соседняя страница про стили и уровни анимации — `plans/style-catalog.md`

## Собрано — 12 блоков

| № | Тип блока | Чем сделано |
|---|---|---|
| 01 | первый экран, кинетический заголовок | CSS keyframes с задержкой по словам, дышащий градиент |
| 02 | полноэкранная фотография с наездом | `position: sticky` + `animation-timeline: view()` |
| 03 | видео фоном секции | `autoplay muted loop playsinline`, без скрипта |
| 04 | видео, перематываемое скроллом | прогресс секции → `video.currentTime` |
| 05 | до / после с ручкой | `clip-path: inset()` + `<input type=range>`, тянется пальцем |
| 06 | галерея-лента | CSS `scroll-snap`, ноль строк JS |
| 07 | мозаика плиток (бенто) | CSS Grid, плитки разного размера |
| 08 | закреплённая сцена со сменой шагов | sticky + прогресс скролла на шагах |
| 09 | цифры и столбцы, растущие при подходе | IntersectionObserver + transition с задержкой |
| 10 | бегущая строка в две полосы | CSS keyframes, вторая полоса реверсом |
| 11 | раскрывающиеся вопросы | `<details>/<summary>`, работает без JS |
| 12 | финал: холст частиц + магнитная кнопка | Canvas 2D вручную + `pointermove` |

Над каждым блоком тёмная липкая плашка: номер, тип блока, чем сделано.

## Источники материала

- Снимки — Openverse через `tools/stock-photos.mjs`, без ключа.
- **Видео — Викисклад** (`upload.wikimedia.org`, transcoded 720p vp9 webm), свободные лицензии.
  Причина: в `.env` нет `PEXELS_API_KEY`, банк видео недоступен. Ключ вписывает владелец.
