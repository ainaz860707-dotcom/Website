# Что за референс

Тёмный сайт стритвир-бренда, снятый телефоном с экрана MacBook, в браузере `localhost` —
чужой локальный проект. Звук не перенесён, закадровый текст неизвестен.

**Ни одного слова и ни одной цифры с этого референса на страницу клиента не переносится**
(§12 CLAUDE.md): `OCTABOOT`, `FORGED`, `$129.00`, «480gsm French terry», «250 pieces
worldwide» — чужие факты. Берём только приёмы движения.

# Стек

**Наш генератор — пресет `story` на CSS + Canvas 2D, без библиотек.**
`position: sticky` — закреплённые сцены; `animation-timeline: scroll()` — прогресс главы;
`IntersectionObserver` — появления текста; секвенция — свой рисовальщик на Canvas 2D
(`tools/motion-directions.mjs`, группа «скролл»). Библиотеки анимации в генераторе
запрещены слоем движения, и обходить запрет здесь незачем: скраб делает `scroll()`,
липкость — `sticky`, кадры — canvas. Не хватает только инерционного сглаживания Lenis —
это удобство, а не требование референса.

**Чужой стек (для понимания, не для подключения):** Lenis + GSAP ScrollTrigger `scrub: true`
+ canvas-секвенция; так собран darkroom.engineering из той же таблицы референсов.

Цена картинки: секвенция ~120 кадров × 1600px webp ≈ 5–7 МБ. Дешевле — скрабить `<video>`
по `currentTime`, но тогда нужна папка ассетов, которой у выдачи пока нет
(`04_not-done`, строка про `HERO_VIDEO`).
