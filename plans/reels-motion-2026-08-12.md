# Три ролика из Instagram — разбор движения и стек

Владелец прислал три ссылки и попросил разобрать типы анимации и предложить стек. Ролики
скачаны `yt-dlp`, нарезаны `ffmpeg` в контактные листы по 2 кадра в секунду и просмотрены
глазами. Ролик 3 — тот же референс, что разобран отдельно в `plans/octaboot-reference.md`.

| # | Что на экране | Длина | Источник |
|---|---|---|---|
| 1 | `alche.studio` — японская студия, прокрутка в браузере | 14 с | адрес виден в строке |
| 2 | шоурил русской студии: шесть корпоративных сайтов подряд | 14,5 с | подпись «бюджет до 1.5 млн» |
| 3 | стритвир-лендинг «Crafted in shadow» | 25 с | `localhost` в строке |

## Ролик 1 — что там за приёмы и чем сделано

Шейдерное искажение слова на первом экране · горизонтальная лента работ с видео-карточками ·
переход между секциями изогнутой плоскостью · переливающаяся градиентная лента в блоке VISION ·
построчное проявление японских строк · сборка логотипа на сетке в финале.

Стек снят с живого сайта, а не предположен: **Astro 5.13.3**, один бандл **1,78 МБ**, внутри
`gsap` + `ScrollTrigger`, `THREE`, `ogl`, `swiper`, `lenis`, `lottie`.

Замер по методике `motion-direction`: **текста в HTML 2715 знаков, блоков разметки ноль.**
Это уровень lusion.co из нашей таблицы — сайт великолепен для глаза и почти нечего процитировать
нейросети. Для студийного портфолио размен осознанный, для страницы, которую ищут, — брак.

## Ролик 2 — самое простое движение из трёх

Видеофоны первых экранов · медленный поворот белой аксонометрии зданий · левитирующая банка
в брызгах · тёмная сцена с металлом · параллакс слоёв и перетекание экранов.

3D там настоящее или предрендеренное видео — по кадрам не различить. Стек проверить не удалось:
`cristall-group.ru` из сети агента не открылся. Фактов по этому ролику нет, только наблюдение.

## Ролик 3 — один приём на весь сайт

Скролл-скраб кадровой последовательности с закреплёнными подписями-главами. Доказательство,
что это скраб, а не автоплей: во второй половине ролика автор скроллит вверх и сцена отыгрывает
те же кадры задом наперёд — кадр привязан к позиции скролла.

## Приёмы на язык каталога `tools/motion-directions.mjs`

| Что видно | Ролик | Ключ | Чем делаем мы |
|---|---|---|---|
| разлёт вещи по скроллу, главы сбоку | 3 | `story` + `pinned` | `position: sticky` + `animation-timeline: scroll()` |
| горизонтальная лента работ | 1 | `horizontal` | `sticky` + `translateX` |
| изогнутая плоскость, градиентная лента | 1 | `webgl` | Three.js по ESM, только на `showcase` |
| построчное проявление, сборка логотипа | 1 | `kinetic`, `reveal` | CSS keyframes + `IntersectionObserver` |
| видеофон, левитирующий продукт | 2 | `ambient`, `webgl` | `<video>` + Canvas 2D либо Three.js |
| слои с разной скоростью | 2 | `parallax` | `animation-timeline: scroll()` |

## Предложенный стек

1. **Пресет `story` на голом CSS (рекомендовано).** `sticky` + `animation-timeline: scroll()`
   для скраба, `IntersectionObserver` для появлений, ноль библиотек. Основание: весь ролик 3 —
   это позиция скролла → номер кадра, ровно то, что даёт `scroll()`. Контр-проверка: скрабься
   там видео (`video.currentTime`), CSS бы не хватило — но на реверсе видны дискретные состояния
   сцены, а не покадровая перемотка. Цена ошибки: видео-скраб добавляется ~15 строками на
   `requestAnimationFrame`, а не библиотекой.
2. **`showcase` + Three.js по ESM** — только ради настоящей геометрии, как в ролике 2.
3. **Повторить стек alche** — отклонено: 1,78 МБ и 2715 знаков текста без разметки.

Сделано по варианту 9 для психолога — `plans/psy-variants.md`.
