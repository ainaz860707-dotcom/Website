# Сервис создания сайтов с SEO и GEO внутри

## Боль и пользователь

Человек делает сайт и остаётся один на один с вопросом «почему его никто не находит».
SEO живёт отдельно от конструктора: сайт собрали в одном месте, аудит заказали в другом,
а рекомендации написаны словами, которых заказчик не понимает. Плюс появился второй канал
трафика — ответы нейросетей (ChatGPT, Perplexity, AI-режимы поиска), и под него почти
никто сайты не готовит.

Пользователь по решению владельца — **любой, кто захочет**: продукт не сужается до одной
ниши. Для проверки скелета первым тестировщиком выступает сам владелец.

## Ключевое действие (сквозной сценарий)

Зашёл → описал своё дело своими словами (кто, что, город, свои идеи) → через полминуты
увидел готовую страницу → опубликовал и получил живую ссылку → рядом увидел панель
«SEO и GEO»: что сделано за него и что дописать самому → поправил текст прямо на странице.

Целевой продукт даёт **три режима на выбор**: генерация по описанию, конструктор блоками,
разбор готового сайта по ссылке. В скелет входит только первый.

## Ходячий скелет v0 (сегодня)

- Экран 1: свободное поле «расскажи о своём деле» + кнопка «собрать сайт».
- Экран 2: готовая одностраничка, кнопка «опубликовать» → живая ссылка, открывается с телефона.
- Экран 3: панель «SEO и GEO» рядом с сайтом — списки «сделано за тебя» и «допиши сам»,
  человеческим языком; часть пунктов чинится кнопкой.
- Экран 4: правка текста кликом прямо на странице (не конструктор блоков).

## Критерий «работает»

Владелец назвал три и потребовал все три:

1. «Сайт, который не стыдно отдать» — проверяется в день запуска, это же критерий пробы ядра.
2. «Понятный план что чинить» — человек без разработчика прочёл панель и сделал сам.
3. «Сайт реально нашли» в ИИ-ответах и поиске — проверяется через 2–4 недели после первой
   публикации, срок индексации от продукта не зависит; вынесено в реестр отложенного.

## Отрезано в «потом»

| Что | Почему сейчас нет | Когда вернуться |
|---|---|---|
| Конструктор блоками (drag&drop) | Недели работы, ядро не проверяет | После зелёной пробы и живого скелета |
| Разбор чужого сайта по ссылке | Не создаёт сайт → не проверяет критерий №1 | Сразу после скелета, движок общий |
| Регистрация, кабинет, оплата | В скелете доступ по секретной ссылке | Решение владельца: деньги + приход чужих людей |
| Многостраничники и свой домен | Скелет проверяется на одной странице | После первых опубликованных сайтов |

## Деньги/аккаунты

- **Проба ядра** идёт через уже оплаченную подписку Claude Code, отдельных списаний нет.
  Расход прогона — около $9 лимита подписки.
- **Продакшен** потребует платного API-ключа: каждый сгенерированный сайт стоит денег.
  Цена одного сайта через CLI-канал — верхняя граница ~$0.45; через прямой API будет
  заметно дешевле, точная цифра — после первого замера на реальном канале.
- Бесплатной альтернативы, дающей нужное качество текста, не найдено.
- Хостинг публикуемых сайтов и домен — решение владельца, поднимается перед публикацией
  первого чужого сайта.
