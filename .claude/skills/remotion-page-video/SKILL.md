# Remotion в этом проекте

Официальные скиллы Remotion установлены (`remotion-best-practices` — роутер, дальше `remotion-create`,
`remotion-markup`, `remotion-studio`, `remotion-render`, `remotion-docs`, `remotion-captions`,
`remotion-maps`, `remotion-multimedia`, `remotion-interactivity`, `remotion-saas`, `remotion-upgrade`).
API, разметка и флаги рендера — оттуда, они версионированы вместе с пакетом. Здесь только то,
чего в них нет: наши границы и наша приёмка.

## Чем делать ролик: код или модель

Развилка решается по тому, что в кадре, а не по вкусу.

| В кадре | Чем | Почему |
|---|---|---|
| текст, цифры, титры, логотип клиента, интерфейс, схема, «до/после», графики, карта, субтитры | **Remotion** | детерминизм: тот же вход даёт тот же кадр, правка текста стоит перерендера, а не новых кредитов |
| дом, интерьер, еда, натура, человек, свет, фактура, «живой» кадр | **Higgsfield** (`hero-video`) | фотореализм кодом не рисуется |

Смешанный случай — генерация даёт фон, Remotion кладёт поверх типографику и данные. Так дешевле:
перегенерация фона нужна один раз, текст меняется бесплатно.

Уровень движения на самой странице выбирает владелец в `motion-direction` — ролик заказывается
после выбора пресета, а не до. В пресетах `interface` и `off` видеофона нет.

## §12 действует и здесь

Remotion выводит в кадр ровно то, что пришло в пропсах. Соблазн вписать в титр «10 лет опыта» или
«более 500 клиентов» — выдуманный факт о бизнесе клиента, блокер на ревью. Текст в композицию
приходит через `defaultProps` и `--props`, не хардкодом в JSX: так видно, что каждая строка пришла
из входа, а не из головы. Нет во входе — плейсхолдер `«…»`, а не правдоподобная цифра.
Отдельно проверяется скиллом `fact-check` до сдачи.

## Где живёт проект

`apps/video` — скелет `create-video` (Remotion 4.0.509, React 19, TypeScript, Tailwind v4).

```bash
cd apps/video
npx remotion studio            # превью глазами, композиция по адресу /<id>
npx remotion render <id> ../../artifacts/<проект>/media/<имя>.mp4
npx remotion still <id> ../../artifacts/<проект>/media/<имя>.png
npm run lint                   # eslint + tsc
```

Готовые файлы кладутся в `artifacts/<проект>/media/`, исходники композиций остаются в `apps/video/src`.
Один проект на все ролики: композиции разделяются `id`, а не копиями скелета.

## Что считается сданным роликом

Требования владельца (2026-08-13), они же приёмка:

- **4–6 секунд.** Длиннее — это не первый экран, это проваленный LCP.
- **16:9 и 9:16 — разные композиции**, а не кроп одной. Кроп ломает композицию кадра;
  в Remotion это дешёвая операция: та же сцена, другие `width`/`height` и своя раскладка.
- **1–1.5 МБ на файл**: VP9/WebM плюс H.264-фолбэк, постером первый кадр.
- **Одна палитра и одна оптика на весь набор**, иначе страница распадается на куски.

Упаковка и замер веса — одной командой, глазомер здесь не работает:

```bash
node tools/video-package.mjs artifacts/<проект>/media/<имя>.mp4
```
Отдаёт `.webm` (VP9 crf 26), `.mp4` (x264 crf 26 preset slow, faststart), `.jpg`-постер и вес
каждого; вышли за 1.5 МБ — резать длительность, а не разрешение.

## Как ролик ложится в вёрстку

`autoplay muted loop playsinline` + `preload="none"`, источники навешиваются IntersectionObserver'ом
на входе блока во вьюпорт: шесть роликов с жадной загрузкой убивают LCP. Проверка — браузером,
`sources: 0` у нижнего ролика до скролла. Готовые блоки под видео уже собраны в
`artifacts/block-reel/index.html`: блок 03 — видео фоном секции, блок 04 — перемотка скроллом.

## Порядок работы

1. `motion-direction` — нужен ли ролик вообще и какого характера.
2. Развилка выше — код или модель.
3. Композиция по официальному `remotion-markup`, текст только из входа клиента.
4. `npx remotion studio` — посмотреть глазами до рендера; рендерить вслепую дорого по времени.
5. Рендер → `tools/video-package.mjs` → числа веса в отчёт владельцу.
6. `fact-check` по тексту в кадре, потом сдача.

## Обновление

`npx skills add remotion-dev/skills` ставит скиллы в `.agents/skills/`, `.claude/skills/` держит
симлинки. Обновление затирает описания, а вместе с ними русские триггеры — без них скилл по
русской фразе молча не вызовется. После каждого обновления:

```bash
node tools/remotion-skill-triggers.mjs
```
Скрипт идемпотентный, повторный запуск ничего не портит.
