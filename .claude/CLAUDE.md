# Политика тулинга — Website

## Код проекта — индекс первым
- `make_context_capsule` (RepoBrain) — на ЛЮБОЙ задаче до `grep`/`glob`/`Read`: по формулировке задачи отдаёт ранжированную капсулу контекста.
- **Английские имена кода — самый точный запрос** (`createLead`, `LeadInput`): поиск по коду лексический. Русский запрос тупиком больше не является: он находит заметки `second-brain/` и через них — описанный ими код (мост «заметка → код», волна 2). Не нашлось по-русски — перезапроси английскими именами, а не решай, что кода нет.
- «Скелет» файла вместо полного `Read`; `Read` — когда нужна точная строка для правки.
- Сырой `grep` — только когда индекс недоступен или нужен буквальный матч по строке.

## Внешние библиотеки — docs-MCP `context7`
API меняется быстрее обучения модели — не полагайся на память. Обязательно: интеграция и обновление версии, незнакомое API, подозрение на breaking change, новая зависимость. Два шага: `resolve` (по названию — `libraryId`) → `query` (вопрос с этим `libraryId`).

## Фронт
browser-MCP (`browser_navigate` / `browser_snapshot` / `browser_click`) — проверяй UI глазами, а не по догадке. Прогон приложения — `npm run dev`.

## Анимация — MCP `gsap`
GSAP-код не пиши по памяти: `understand_and_create_animation` (запрос словами → готовая анимация), `get_gsap_api_expert` (точное API метода или плагина), `generate_complete_setup` (подключение плагинов под фреймворк), `debug_animation_issue`, `optimize_for_performance`. Выбор приёма движения остаётся за скиллом `motion-direction`, MCP даёт реализацию.

## Данные поиска и SEO — MCP `dataforseo`
Частотность, выдача, конкуренты, бэклинки, аудит страницы — из API, а не из головы. Инструменты: `docs_list_sections` / `docs_index` (какие эндпоинты есть) → `docs_search` (параметры конкретного эндпоинта) → `api_request` (сам запрос). Порядок обязателен: список параметров сочинять нельзя. Ключи ниши и разбор топа для `niche-benchmark` берутся отсюда.
**Граница с §12:** DataForSEO даёт факты о рынке и конкурентах, а не о бизнесе клиента. Цены, стаж, отзывы, адрес клиента с чужих страниц НЕ переносятся — во входе не сказано, значит плейсхолдер.
Транспорт — remote HTTP с OAuth (`https://mcp.dataforseo.com/mcp`), логин и пароль на диске не лежат; авторизация — команда `/mcp` в Claude Code.

## Видео и картинки под страницу — Higgsfield (CLI + MCP)
Ролик на первый экран, фон секции и опорный кадр генерируются моделью, а не подбираются на глаз.
**На пробном плане CLI не генерирует:** `generate create` отвечает `{"error_type":"only_mcp_usage_on_trial_is_available"}` — на триале разрешён только MCP-канал (проверено 2026-08-12, аккаунт plus/trial, 110 кредитов, списания не было). Разведка через CLI работает и на триале: `model list`, `model get`, `generate cost` бесплатны и отвечают. Значит порядок такой: **цены и параметры считаем CLI, саму генерацию зовём через MCP**; после снятия триала CLI генерирует сам.
**Путь CLI** (`@higgsfield/cli` 1.1.23, команды `higgsfield` · `higgs` · `hf`; официально рекомендован для Claude Code вместо коннектора). Порядок: `higgsfield model get <job_type>` — какие параметры принимает модель, имена не сочинять → `higgsfield generate cost <model> --prompt "…"` — **цена до генерации, обязательный шаг** → `higgsfield generate create <model> --prompt "…" --start-image ./кадр.png --wait` → файл в `artifacts/<проект>/media/`. Медиа-флаги принимают локальный путь и заливают его сами. Вход — `higgsfield auth login` (браузерный OAuth, аккаунт владельца), затем `higgsfield workspace set <id>`: без выбранного workspace CLI отвечает «No workspace selected», а не «не авторизован» — не спутать.
MCP-канал того же сервиса остался в `.mcp.json` (`https://mcp.higgsfield.ai/mcp`, remote HTTP + OAuth, вход командой `/mcp`) на случай, когда удобнее инструментами. До входа сервер отдаёт `401`, список инструментов не читается и по памяти не называется — сверяй на месте после входа.
Промпт собирается не руками: четыре части (объект · свет · движение камеры · назначение) и техзадание под назначение даёт `node tools/video-prompts.mjs`, правила разбора — скилл `hero-video`. Сначала опорный кадр картинкой, показать, потом ролик: перегенерация кадра дешевле ролика. Подписка и кредиты — решение владельца (§1).
**Граница с §12:** объект в кадре родовой. Вывеска, лицо, номер машины, логотип в кадре — выдуманный факт о бизнесе клиента, блокер на ревью; хвост промпта `no text, no signage, no logos, no faces` обязателен.

## Видео кодом — Remotion (`apps/video`)

Ролик, где в кадре типографика, цифры, схема, интерфейс, карта или субтитры, собирается кодом,
а не генерацией: правка текста стоит перерендера, а не новых кредитов, и кадр воспроизводится
побитово. Натура, интерьер, еда, свет — по-прежнему Higgsfield.
Официальные скиллы установлены (`.agents/skills/remotion-*`, симлинки в `.claude/skills/`):
роутер `remotion-best-practices`, дальше `remotion-create` · `remotion-markup` · `remotion-studio` ·
`remotion-render` · `remotion-docs` · `remotion-captions` · `remotion-maps` · `remotion-multimedia` ·
`remotion-interactivity` · `remotion-saas` · `remotion-upgrade`. API и флаги — оттуда, по памяти не писать.
Наши границы (что кодом, что моделью; §12 в титрах; вес и вёрстка) — скилл `remotion-page-video`.
Установка и обновление: `npx skills add remotion-dev/skills`, после каждого обновления —
`node tools/remotion-skill-triggers.mjs` (апдейт затирает описания вместе с русскими триггерами,
без них скилл по русской фразе не вызовется).

## Безопасность кода и зависимостей — MCP `snyk`
Уязвимости ищутся сканером, а не глазами. Обязательно: перед мержем в `strict-production-review-gate`, при добавлении новой зависимости (§10а — вместе с `context7`), перед деплоем. Основное: `snyk_code_scan` (SAST по своему коду), `snyk_sca_scan` (зависимости; путь ТОЛЬКО абсолютный), `snyk_package_health_check` (здоровье пакета до установки), `snyk_breakability_check` (ломающие изменения при апгрейде версии), `snyk_container_scan`, `snyk_iac_scan`, `snyk_sbom_scan`.
Первый скан по новой папке требует `snyk_trust` с абсолютным путём. Авторизация — `snyk_auth` (браузер) или `SNYK_TOKEN` в ENV; без неё сканы вернут «not authenticated».
Найденное сканером — факт, а не мнение: «уязвимостей нет» без прогона — брак по §1.

## Готовые UI-компоненты — MCP `magicui`
Реестр Magic UI (React + Tailwind + Framer Motion) до того, как писать анимированный блок руками — §10а «не изобретай велосипед». Инструменты: `searchRegistryItems` (по задаче), `listRegistryItems` (обзор по `kind`), `getRegistryItem` (`includeSource: true` — исходник компонента). Взятый компонент подчиняется арт-дирекшену ниши и пресету `motion-direction`, а не наоборот.
